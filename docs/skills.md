# Skills para trabajar en Monopiston

Instaladas en Codex el 1 de octubre de 2026. Estarán disponibles en el siguiente
turno. Son herramientas de desarrollo y no dependencias de la aplicación.

| Skill                   | Uso                                                                                 | Fuente                                                                            |
| ----------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `caveman`               | Respuestas breves sin perder precisión técnica; uso opcional.                       | https://github.com/JuliusBrussee/caveman/tree/main/skills/caveman                 |
| `playwright`            | Automatización del navegador y revisión de flujos y responsive; ya instalada.       | https://github.com/openai/skills/tree/main/skills/.curated/playwright             |
| `frontend-design`       | Identidad visual, tipografía, composición, accesibilidad y revisión de interfaces.  | https://github.com/anthropics/skills/tree/main/skills/frontend-design             |
| `architecture-designer` | Evaluar mantenibilidad, escalabilidad, costos, fallos y decisiones de arquitectura. | https://github.com/Jeffallan/claude-skills/tree/main/skills/architecture-designer |

Las skills nuevas se instalaron con el instalador oficial de Codex desde sus
repositorios fuente. Playwright ya estaba instalado. `frontend-design` se eligió
por su enfoque en interfaces con identidad y `architecture-designer` por su
tratamiento explícito de requisitos no funcionales y mantenimiento; no existe una
skill universalmente mejor para todos los productos.

En este producto, mantener los módulos existentes, medir antes de escalar y
verificar los flujos de reserva y pago antes de publicar. Las instrucciones del
usuario y del proyecto tienen prioridad sobre las recomendaciones de las skills.
